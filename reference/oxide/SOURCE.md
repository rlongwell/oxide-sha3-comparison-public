# Oxide Quartz reference

These files are unchanged copies of the public Oxide Quartz repository at commit `c0ccf08525f30c43f4c773c2295dabe80f97cd0e`. `SOURCE.json` records each exact URL and SHA256 digest; `SHA256SUMS` is checked before builds. All upstream RTL MPL-2.0 notices are retained, and `MPL-2.0.txt` contains the license text.

The source was introduced in [PR 516](https://github.com/oxidecomputer/quartz/pull/516), merged as `cfb69fed85c24b500c0452aa7b36cc8bacc2ddff`. The pinned version differs only in port-view alias spelling, changed by [PR 538](https://github.com/oxidecomputer/quartz/pull/538); the hash algorithm is unchanged.

No local patches are applied. Wrappers, independent tests, and tool setup live outside this directory. VHDL-2019 is required.
